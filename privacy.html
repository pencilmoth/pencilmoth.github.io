pencil moth analytics: privacy policy

Last updated: 16 November 2026

"pencil moth analytics" is a private tool used only by the operator of the pencil moth YouTube channel. It is not offered to the public, and no one else can sign in to it.

What it accesses

With the channel owner's permission, the tool uses two read-only Google permissions:

  • youtube.readonly: to read the pencil moth channel's own videos and their public statistics.
  • yt-analytics.readonly: to read the pencil moth channel's own YouTube Analytics reports (for example views, watch time and traffic sources).

The tool cannot upload, edit, delete or publish anything, and it never reads any other person's account or data.

How the data is used

The statistics are saved on the channel operator's own computer and used only to plan the channel's releases. They are not sold, shared with third parties, used for advertising, or used to train AI models.

Storage and security

The sign-in token is kept in the operating system's secure keychain on the operator's computer and is never stored in a file or sent anywhere except to Google.

Removing access

Access can be revoked at any time from the Google Account's "Third-party apps and services" page, which stops the tool from reading anything further.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Contact

Questions can be sent through the contact details on the pencil moth YouTube channel.
